# 二游毕业指导 · 项目文件说明

> 版本：v1.9.2 ｜ 说明：项目中**每一个文件**的作用（具体到代码文件），按目录分组。
> 局域网文档页：`http://<本机IP>:8000/docs`（本文件可加入该页）。

---

## 目录总览

```
二游毕业指导/
├── app/                  # 后端核心包（FastAPI + 引擎 + 种子 + 采集插件）
│   ├── collectors/       # 采集插件（file/clipboard/sample/ocr/auto）
├── web/                  # 前端（纯中文 vanilla JS，无框架）
├── scripts/              # 运维/测试/演示脚本
├── tests/                # 自动化测试
├── tools/                # 伴生工具（PC 端自动点击导出器）+ 离线样例
├── data/                 # 运行时数据（数据库/日志/采集结果，git 忽略）
├── _archive/             # 归档区（弃用文件）
├── *.bat                 # 一键启动脚本
└── *.md / *.txt / .env   # 文档与配置
```

## 二、app/（后端核心包）

| 文件 | 作用 |
|---|---|
| `__init__.py` | 包标记（47B，空） |
| `main.py` | **FastAPI 入口**：全部路由。API：`/api/v1/health`、`games`、`sample`、`characters`、`collect`、`analyze`、`graduate`（含 `key_stats`）、`recommend`/`batch`、`team(s)/recommend`、`standards`（GET/PUT）、`assets`（GET/POST/DELETE 四类保存）、`advice`、`auto-click/{start,status,stop}`、`test-data/generate`；`/docs` 文档页；静态挂载 `web/`；CORS 限本机/局域网 |
| `config.py` | 全局配置：`GYZ_DB_PATH`、组件开关（`GYZ_USE_FASTTEXT`/`GYZ_USE_RF`）、DeepSeek 端点/密钥；零依赖 `.env` 加载器（环境变量优先） |
| `database.py` | SQLite 层：`SCHEMA`（game/entity/kb_build/kb_graduation/kb_recipe/**kb_weapon**/kb_team/user_standard/user_feedback/**user_asset(含 type 列)**/team_graduate/ocr_sample）、`DROP_SCHEMA`、幂等迁移（game 缺列重建、user_asset 加 type）、`query/query_one/execute/now_iso` |
| `schemas.py` | Pydantic 请求模型：`AnalyzeReq`/`GraduateReq`/`RecommendReq(s)`/`StandardsReq`/`TeamReq(s)`/`AssetsSaveReq`/`CollectReq`/`FeedbackReq`/`AdviceReq`/`AutoClickReq`/`TestDataReq` |
| `pipeline.py` | **识别管线**：`extract_lines`（RapidOCR 主 + paddle 兜底 + 模拟文本）、正则库（主词条/等级/材料数量/命座/天赋）、`match_entity`（别名+difflib）、`analyze_lines`（文本行 → 结构化资产：角色/武器/装备/材料，含数值） |
| `engine.py` | **决策引擎**：`merge_standard`（默认+全局模板+**角色专属 tiers**+overrides 递归合并）、`_apply`、`load_effective_standard`、`evaluate`（等级/武器/套装/主词条/副词条/技能等级逐项评估 + 差距清单 + 权重分摊）、`recommend_builds`/`recommend_batch`、`team_recommend`/`teams_recommend`、`material_holdings`/`material_gaps`（按目标折算）、`cultivation_advice`（培养建议文本 + 刷取优先级 + LLM 润色）、`llm_explain`/`llm_polish_advice` |
| `seed.py` | **种子数据（v7）**：三游戏注册（含 `max_team_size`）、`CHAR_MATERIALS`（66 角色升级材料）、`WUTHERING/ZZZ_ELEMENTS`、`DATA`（角色/武器/套装/配装/配队）、**`KEY_STATS`（66 角色关注属性）**、`_graduation_from_build`/`_graduation_tiers`（专属 3 档）、`_gen_recipes`（角色/技能/武器配方）、`seed_all`（建表+灌数据+版本检查） |
| `kb_expand.py` | 知识库扩充（`EXTRA`）：原神 36 角色+28 配装+24 套装+武器别名、鸣潮/绝区零武器套装，`seed_all` 合并进基础 DATA |
| `kb_weapons.py` | **武器知识库（150 件真实数据）**：名称/星级/类型/基础攻击(90级)/主词条(+数值)/被动；含 50 件 5★（星鹫赤羽/若水/护摩…新专武苍耀/焚曜千阳等） |
| `kb_materials.py` | **材料知识库（400 种真实数据）**：8 分类（天赋书 54/角色突破 44/特产 61/武器突破 48/周本 18/怪物掉落 71/经验货币 15/食材 90），每项含来源；`UPGRADE_CATS` 标记升级相关（240 种） |
| `team_alloc.py` | 队伍全局武器分配：`hungarian_maximize`（匈牙利算法）+ `greedy_with_backtrack`（贪心回溯兜底） |
| `sample_data.py` | 示例账户文本行：每游戏一份"完整背包"（约 10 角色+武器+装备+材料） |
| `auto_click.py` | **伴生工具网页接入**：`start`（subprocess 启动 auto_export.py，参数白名单+路径限定+UTF-8 日志）、`status`（解析进度/已收集/完成/错误+候选窗口）、`stop`（终止，断点可续采） |
| `test_data.py` | **测试数据实时生成器**：`generate_assets`（66 角色[5星≥36 等级≥70]/150 武器[5星≥50]/1000 圣遗物[等级≥16]/400 材料）、`generate_test_account`（写入 user_asset，时间戳=当前） |
| `md_render.py` | 零依赖 Markdown→HTML 渲染器（标题/表格/代码块/列表/引用）+ 文档页 CSS/模板（`/docs` 用） |

### app/collectors/（采集插件：统一输出文本行→pipeline；auto 例外直转资产）

| 文件 | 作用 |
|---|---|
| `__init__.py` | 插件注册表 `COLLECTORS`（file/clipboard/sample/ocr/auto）+ `run_collector`（执行插件→统一识别管线；auto 特判直转） |
| `file_collector.py` | **导出文件导入**：解析 JSON（characters/weapons/artifacts/materials）→ 文本行；`adapt_common` 兼容字段名差异 |
| `clipboard_collector.py` | **剪贴板/粘贴框导入**：文本直接转行 |
| `sample_collector.py` | **示例账户**：返回 `sample_data` 文本行 |
| `ocr_collector.py` | **截图兜底**：OCR 图片→文本行（浏览器读屏/上传截图用） |
| `auto_collector.py` | **伴生工具结果直转**：读 auto_export 输出的 JSON（set/slot/main/substats）→ 资产数组（路径限定项目目录，不经二次解析） |

## 三、web/（前端，纯中文 vanilla JS）

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架：开局选游戏弹窗、顶栏（游戏/主题切换）、侧边栏（5 导航 + 账户资产汇总）、资产识别（读屏/上传/粘贴/自动导入 + 伴生工具自动点击卡片 + 导入测试数据）、毕业度评估、配装推荐、队伍配置、毕业标准（7 滑块+技能 3 滑块+自定义词条+置灰提示）、资产详情弹窗 |
| `app.js` | 全部前端逻辑（45KB）：API 封装、游戏/主题切换、资产识别与四类分组渲染、**点击详情弹窗**、毕业度/配装/队伍/建议渲染、**毕业标准（key_stats 置灰）**、伴生工具自动点击（轮询进度/断点/载入）、**导入测试数据**、侧边栏资产统计、启动 boot（**不再自动加载资产**） |
| `style.css` | 全部样式：4 套主题变量（蓝紫/森林绿/樱花粉/暗夜）、固定顶栏与侧边栏、std-item 置灰样式、详情弹窗、表格/卡片/标签 |
