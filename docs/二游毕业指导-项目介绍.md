# 二游毕业指导 · 项目介绍

> 版本：v1.9.1 ｜ 类型：项目介绍（含数据采集决策树与局域网访问说明）

---

## 1. 项目定位

**二游毕业指导**是一个面向二次元游戏玩家的「角色毕业」指导工具：识别玩家游戏账户内的资产（角色、武器、装备、材料），评估角色离「毕业」还差多少，并给出个性化的配装与培养建议。

> 一句话：**让玩家知道"我的角色离毕业还差什么、现在该怎么养、配什么最合适"。**

支持游戏：**原神**（66 角色/150 武器/44 套装，主）、**鸣潮**、**绝区零**（共 3 款，可自由切换）。

## 2. 背景与痛点

二次元抽卡游戏的核心长期玩法是「角色毕业」——把角色养成到理想状态。玩家普遍面临：

- **信息分散**：配装攻略散落各处，口径不一；
- **版本漂移**：一个版本更新就可能推翻旧配装；
- **不知从何下手**：新玩家面对大量养成材料不知道优先养什么；
- **无法个性化**：通用攻略不考虑玩家已有资产，照抄往往缺关键材料。

## 3. 功能一览

| 功能 | 说明 |
|---|---|
| 开局选游戏 | 首次进入先选择游戏，随时可切换（称谓自动切换：圣遗物/声骸/驱动盘） |
| 资产识别 | 读屏扫描 / 上传截图 / 粘贴文本 / 导出文件导入 / **伴生工具自动点击** → 四类资产（角色/武器/装备/材料）数值级识别 |
| **资产四类分开保存** | 独立格式：武器（星级/类型/等级/精炼/基础攻击/主词条/被动）、圣遗物（部位/套装/主副属性数值）、材料（数量/来源）、角色（命座/技能等级） |
| **点击查看详情** | 资产列表任意项点击弹出完整详情（含识别置信度/原文） |
| 账户资产速览 | 侧边栏实时显示四类数量，无数据时提示导入 |
| 毕业度评估 | 对照毕业标准计算完成度与差距清单 |
| **每角色专属毕业标准** | 66 角色独立「关注属性」（胡桃看生命/精通，防御力无用置灰；诺艾尔看防御…），**3 档专属毕业**（休闲/标准/极限） |
| 配装推荐 | 可同时选择 **1~9 人**，批量生成各自配装方案 |
| 培养建议（可复制） | 升级路径、材料缺口、刷取优先级、技能加点、配装（LLM 润色，可降级模板） |
| 材料缺口计算 | 角色突破/技能/武器升级配方（三游戏专属材料，真实向数值） |
| 队伍配置 | 1~4 队，人数按游戏（**原神/鸣潮 4 人，绝区零 3 人**），全局武器分配 + 培养顺序 |
| 毕业标准自定义 | 4 档切换 + 滑杆 + 自定义词条，实时对比「系统 vs 我的」 |
| **导入测试数据** | 一键实时生成 **66 角色/150 武器/1000 圣遗物/400 材料**（真实数据，约 8s） |
| 界面 | 4 套主题（蓝紫/森林绿/樱花粉/暗夜）、固定顶栏与侧边栏 |

## 4. 数据采集决策树（什么场景用哪种方式）

| # | 方式 | 用户操作 | 能拿到 | 依赖 |
|---|---|---|---|---|
| ① | 示例/测试数据 | 点一次按钮 | 66 角色/150 武器/1000 圣遗物/400 材料 | 无 |
| ② | 粘贴文本 | 照着游戏打字 | 名称+等级+可手写属性 | 无 |
| ③ | 上传截图 | 游戏内截图→上传 | 当前画面文本 | RapidOCR |
| ④ | 网页读屏 | 浏览器授权选窗口+自己翻页 | 当前画面文本 | RapidOCR + toumanfen |
| ⑤ | 导出文件导入 | 第三方工具导出→选文件 | 完整属性 | 导出工具 |
| ⑥ | 伴生工具自动点击 | 网页一键开启，**零参与** | 详情页全套数值 | PC + pyautogui，坐标校准 |

```
要导入数据？
├─ 只想快速演示/测试 → ① 导入测试数据
├─ 不在电脑前（手机）→ 能导出文件 ? ⑤ : ③/②
└─ 在电脑前（PC）
    ├─ 只要清单 → ④ 网页读屏 / ③ 截图
    └─ 要完整属性 → 有导出工具 ? ⑤ : ⑥ 伴生工具自动点击（网页一键，断点续采）
```

关键提醒：列表页 ≠ 详情页（**主/副词条数值在详情页**）；浏览器只能"看"不能"点"（④ 拿不到详情数值，⑥ 是网页内唯一自动点击路径）。

## 5. 系统架构

```
感知层：读屏(getDisplayMedia) / 上传截图 / 粘贴文本 / 导出文件 / 伴生工具自动点击(⑥)
   ↓
理解层：OCR(RapidOCR) → 采集插件(file/clipboard/sample/ocr/auto) → 实体链接 → 结构化资产
   ↓
决策层：毕业标准(每角色专属 3 档) → 毕业度评估 → 配装推荐(Hungarian/RF) → 材料缺口 → 培养建议(LLM 润色)
   ↓
存储层：SQLite（user_asset 四类分开 / kb_weapon / kb_graduation / kb_recipe）
```

技术栈：FastAPI + Uvicorn ｜ 零依赖 sqlite3 ｜ 纯中文 vanilla JS 前端 ｜ RapidOCR(onnxruntime) ｜ PyTorch/fasttext/sklearn 可选 ｜ DeepSeek API（.env 管理）。

## 6. 局域网访问

服务默认绑定 `0.0.0.0`，同一局域网内任意设备（手机/平板/另一台电脑）可访问：

```
http://<本机IP>:8000/        # 应用主界面
http://<本机IP>:8000/docs    # 文档页（本文件 + 技术文档 + 数据采集决策树）
```

查本机 IP：`ipconfig`（IPv4 地址），或运行 `python -c "import socket; print(socket.gethostbyname(socket.gethostname()))"`。

> 提示：Windows 防火墙首次可能拦截，放行 Python/8000 端口即可；云游戏等场景使用 ⑥ 伴生工具时需在同一台电脑上。

## 8. 合规边界与诚实声明

- 伴生工具仅在你自己的电脑/账号上运行：**只读截图 + 模拟点击详情/返回**，不注入、不修改游戏文件；云游戏/浏览器需 `--calibrate` 校准坐标（支持 `--viewport` 画面区域）
- 测试数据为真实向：武器/角色/材料名与属性真实（新 5★ 专武被动标注"以游戏内为准"；个别纳塔角色 boss 材料为社区口径）
- 毕业标准为社区主流口径（参考米游社/B站），冷门玩法可用「自定义词条」补充
