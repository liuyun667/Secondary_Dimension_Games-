# 二游毕业指导 · 技术文档

> 版本：v1.9.1 ｜ 状态：持续迭代中
> 定位：面向二次元游戏玩家的「角色毕业」指导工具——识别玩家游戏资产，评估毕业进度，给出个性化配装与培养建议
> 变更历史见 `CHANGELOG.md`；本文件为技术基线文档，与运行代码保持一致。

---

## 1. 项目概述

### 1.1 背景

二次元抽卡游戏（原神、鸣潮、绝区零）的核心长期玩法是**「角色毕业」**。玩家普遍面临：信息分散、版本漂移、不知从何下手、无法个性化。本项目把"账户资产识别 + 毕业度评估 + 配装推荐 + 材料缺口 + 培养建议"整合为一条完整链路。

### 1.2 产品定位

> 输入：玩家游戏资产（读屏/截图/粘贴/导出文件/伴生工具自动采集）；输出：毕业度评估 + 配装 + 培养建议（可复制文本）+ 队伍配置。

支持游戏：**原神**（66 角色 / 150 武器 / 44 圣遗物套装）、**鸣潮**（10 角色）、**绝区零**（10 角色），随时可切换。

### 1.3 核心功能

| 功能 | 说明 |
|---|---|
| 资产识别 | 读屏/上传截图/粘贴文本/导出文件导入/伴生工具自动点击 → RapidOCR → 实体链接 → 结构化（数值级） |
| **资产四类分开保存** | 角色/武器/圣遗物/材料独立格式（字段见 §4），三游戏称谓自动切换（圣遗物/声骸/驱动盘） |
| 角色详情 | 命座、技能等级（普攻/战绩/爆发）识别与展示 |
| 毕业度评估 | 对照毕业标准（档位可调）计算完成度与差距清单 |
| **每角色专属毕业标准** | 66 位角色独立「关注属性」（KEY_STATS，社区口径）——无用属性（如胡桃防御力）置灰不参与评估 |
| 配装推荐 | 1~9 人批量生成配装（知识库检索 + 命中率 + RF 评分 + LLM 解释） |
| 培养建议 | 按角色 + 毕业档位输出**可复制文本**：升级路径/材料缺口/刷取优先级/技能加点/配装 |
| 材料缺口 | 角色突破/技能/武器升级配方（三游戏专属材料）与用户已有对比 |
| 队伍配置 | 1~4 队；**配对人数按游戏**（原神/鸣潮=4，绝区零=3）；全局武器分配 |
| 毕业标准自定义 | 休闲/标准/极限**专属 3 档** + 滑杆 + 自定义词条，实时对比「系统 vs 我的」 |
| 测试数据 | 一键实时生成 66 角色/150 武器/1000 圣遗物/400 材料（真实数据，时间戳=点击时刻） |

### 1.4 非功能需求

| 项 | 要求 |
|---|---|
| 单图识别端到端时延 | CPU ≤ 3s（P95），GPU ≤ 1s |
| 物品名识别准确率 | ≥ 90%（alias 字典 + difflib 兜底） |
| 大数据量评估 | 1616 项资产毕业评估 < 0.1s |
| 部署形态 | 单机 FastAPI + SQLite + 纯静态前端（局域网可访问） |

## 2. 系统架构

```
浏览器（纯中文 vanilla JS）          FastAPI 后端                  SQLite
┌──────────────────────┐  HTTP/JSON  ┌────────────────────────┐  ┌──────────┐
│ 资产识别/毕业度/配装/ │ ──────────► │ app/main.py 路由        │─►│ gyz.db   │
│ 队伍/毕业标准/详情弹窗 │ ◄────────── │ pipeline 识别           │  │ game     │
│ 主题切换(4套)         │             │ engine 评估/推荐/建议    │  │ entity   │
│ 伴生工具自动点击(网页) │             │ collectors 采集插件      │  │ kb_*     │
└──────────────────────┘             │ auto_click 进程管理      │  │ user_*   │
                                     │ seed 种子(v7)           │  └──────────┘
                                     └────────────────────────┘
```

- **采集插件**：file/clipboard/sample/ocr/**auto**（伴生工具结构化结果直转），统一输出资产数组
- **伴生工具** `tools/auto_export.py`：pyautogui 自动点击详情页 + OCR（断点续采/进度/容错/画面区域 viewport），可由网页一键开启
- **可选能力**：RapidOCR 识别、fasttext 分类、RF 评分、DeepSeek LLM 润色（`GYZ_*` 环境变量开关，`.env` 管理）

## 3. 数据模型（v7 种子）

### 3.1 表结构

| 表 | 用途 |
|---|---|
| `game` | 游戏（code/weapon_name/equipment_name/**max_team_size**） |
| `entity` | 实体（角色/武器/装备/材料，含别名/稀有度）——原神 66 角色 + 150 武器 + 44 套装 |
| `kb_build` / `kb_graduation` | 配装知识库 + 毕业标准（**criteria.tiers 专属 3 档** + KEY_STATS 关注属性） |
| `kb_weapon` | 武器固有属性（类型/基础攻击/主词条/被动）——150 件真实数据 |
| `kb_recipe` | 角色升级/技能/武器升级配方（三游戏专属材料） |
| `kb_team` | 推荐配队 |
| `user_standard` | 用户自定义毕业标准（overrides JSON） |
| `user_asset` | **用户资产（type 列区分四类，stats JSON 存明细）** |
| `user_feedback` / `team_graduate` / `ocr_sample` | 反馈/队伍结果/OCR 样本 |

### 3.2 毕业标准合并

```
生效标准 = 默认(社区) + 全局模板(tier) + 角色专属档位(criteria.tiers[tier]) + 用户自定义(overrides)
```

优先级：**角色专属档 > 全局模板 > 默认标准**。`_apply` 支持递归 dict 合并、`_append` 列表追加、`"off"` 关闭维度。

### 3.3 每角色关注属性（KEY_STATS）

- 66 位角色各自配置 2~4 条「关注属性」（参考米游社/B站攻略）：主C看暴击/爆伤/攻击（或生命），副C加充能，辅助看生命/防御/精通/充能
- `graduate` 返回 `key_stats`；前端把**非关注属性置灰禁用**（如胡桃防御力），提交跳过 → 评估不参与
- 例：胡桃=暴击率/暴击伤害/生命值/元素精通；诺艾尔=防御力/暴击/爆伤/充能；砂糖=精通/充能/暴击

### 3.4 专属 3 档毕业（criteria.tiers）

| 档位 | 角色等级 | 武器等级 | 副词条目标 | 技能等级 |
|---|---|---|---|---|
| 休闲 | 80 | 80 | ~60% | 8/8/8 |
| 标准 | 90 | 90 | 100% | 9/9/9 |
| 极限 | 90 | 90 | ~120% | 10/10/10 |

## 4. 资产四类保存格式

`user_asset.type` 区分四类，明细在 `stats` JSON：

| 类型 | 关键字段 | 示例 |
|---|---|---|
| 角色 | rarity/level/constellation/talents | 恰斯卡 ★5 Lv.90 命座0 技能 6/8/6 |
| 武器 | weapon_type/refinement/base_atk/main_stat/passive | 星鹫赤羽 弓 Lv.90 精炼4 608 暴击伤害66.2% 眸中的月珥 |
| 装备（圣遗物/声骸/驱动盘） | set/slot/main_stat(+value)/substats(+value) | 黑曜秘典·生之花 Lv.20 主生命值4780 副暴击率13.2% |
| 材料 | material_qty/source/upgrade | 晶核 ×234 来源：抓捕晶蝶采集 |

三游戏称谓经 `game.weapon_name/equipment_name` 自动切换。

## 6. 运行方式

```powershell
# 全功能（RapidOCR/fasttext/RF/LLM）
启动.bat          # 或：
$env:GYZ_USE_FASTTEXT=1; $env:GYZ_USE_RF=1
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
# 轻量（仅 Web，系统 python 即可）
启动-轻量.bat
```

浏览器访问：本机 `http://127.0.0.1:8000/`；局域网 `http://<本机IP>:8000/`（见 `/docs` 文档页）。

## 7. 合规边界与诚实声明

- **伴生工具**仅在你自己的电脑/账号上运行：只读截图 + 模拟「点击详情/返回」，不注入、不修改游戏文件；云游戏/浏览器场景需 `--calibrate` 校准窗口与坐标（支持 `--viewport` 画面区域）
- **测试数据**为真实向（武器/角色/材料名与属性真实；新 5★ 专武被动标注"以游戏内为准"；个别纳塔角色 boss 材料为社区口径）
- **毕业标准**为社区主流口径，冷门玩法可用「自定义词条」补充
